# Painel de indicadores de RH no Excel

acompanhar a equipe com números e apoiar decisões de gestão.

## O que tem aqui
- **Painel de indicadores** (`modelos/painel-rh.xlsx`): Rotatividade, absenteísmo, tempo e custo de contratação, com gráficos.
- **Relatório mensal** (`modelos/relatorio-mensal.docx`): Modelo de uma página para escrever a análise do mês.

## Como funciona
- **Etapas:** escolher os indicadores, coletar os dados todo mês, montar fórmulas e gráficos e escrever um relatório de uma página com a análise.
- **Entregas:** planilha-painel e relatório mensal.
- **Indicadores:** rotatividade, absenteísmo, tempo de contratação e custo por contratação.
- **Base:** cursos de People Analytics Aplicado ao RH (Udemy) e Excel (SENAI).
